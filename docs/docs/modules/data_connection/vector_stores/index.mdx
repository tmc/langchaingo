# Getting Started: Vector Stores

<Info>
[Conceptual Guide](https://python.langchain.com/docs/modules/data_connection/vectorstores)
</Info>

A vector store is a particular type of database optimized for storing documents and their [embeddings](../../model_io/models/embeddings/index.mdx), and then fetching of the most relevant documents for a particular query, ie. those whose embeddings are most similar to the embedding of the query.
