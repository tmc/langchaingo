# Data Connection 

<Info>
[Conceptual Guide](https://python.langchain.com/docs/modules/data_connection/indexing)
</Info>

Many LLM applications require user-specific data that is not part of the model's training set. LangChain gives you the 
building blocks to load, transform, store and query your data via:

- [Document loaders](document_loaders/index.mdx): Load documents from many different sources
- [Text splitter](text_splitters/index.mdx): Split documents and texts
- [Vector stores](vector_stores/index.mdx): Store and search over embedded data
- [Retrievers](retrievers/index.mdx): Query your data
