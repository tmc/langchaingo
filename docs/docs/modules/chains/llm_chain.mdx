# Getting Started: LLMChain

<Info>
[Conceptual Guide](https://python.langchain.com/docs/modules/chains)
</Info>

An `LLMChain` is a simple chain that adds some functionality around language models. It is used widely throughout LangChain, including in other chains and agents.

An `LLMChain` consists of a `PromptTemplate` and a language model (either an [LLM](../model_io/models/llms/index.mdx) or [chat model](../model_io/models/chat/index.mdx)).
