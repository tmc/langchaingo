# Model I/0

Working with language models can often be divided into three steps. 

 - Firstly constructing the input to the model. In langchain this is done using the [prompts package](prompts/index.mdx).
 - Next the input must be sent to the model. This is easy to do using the [model package](models/index.mdx). 
 - In many cases, information needs to be extracted from the model output. Doing this is simple using the [output parser package](output_parsers/index.mdx)
